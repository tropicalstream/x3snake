# X3 Snake

X3 Snake is a synthwave reimagining of Snake for the RayNeo X3 Pro AR glasses, rendered as glowing neon vector graphics with particle bursts and smoothly interpolated motion on a pure-black canvas, so the trail floats as light directly in the wearer's field of view. The snake grows, speeds up, and bursts into particles on collision, all drawn through a custom rendering path built directly on the Android SDK with no external graphics dependencies. It's a compact, polished take on a familiar format built to show off the studio-quality look the rest of the RayNeo X3 catalog carries.

## Controls

- Swipe up, down, left, or right on the right temple pad to turn
- Tap (light touch or firm click) to start, and to restart after game over
